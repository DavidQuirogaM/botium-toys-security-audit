# Botium Toys Security Controls & Compliance Audit

## Project Overview

This project documents a security controls and compliance audit performed for Botium Toys, a fictional organization used as part of a cybersecurity training scenario.

The purpose of the assessment is to review the organization's existing security controls, identify security and compliance gaps, and develop risk-based recommendations to improve its overall security posture.

## Audit Scope

The assessment covers Botium Toys' security program, including:

- Administrative and managerial controls
- Technical controls
- Physical and operational controls
- PCI DSS best practices
- GDPR best practices
- SOC security principles

## Initial Risk Assessment

**Risk Score: 8/10 — High**

The initial assessment indicates that the organization has several security control and compliance gaps that require further analysis and remediation.
